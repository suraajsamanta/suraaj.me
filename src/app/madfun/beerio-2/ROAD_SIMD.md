# Road projection SIMD128

`road-simd.ts` accelerates the existing expanded-cell nearest-road lookup rather
than adding a second simulation. Every SIMD128 operation projects two candidate
segments using `f64x2`, preserving JavaScript's double precision. The winner is
reconstructed in JavaScript for road height, lateral limits and race progress.
Candidates retain ascending indices so equal-distance ties select the same segment
as the scalar implementation. Odd candidate lists duplicate the final segment.

The 341-byte WASM module is generated by the readable, dependency-free
`build-road-simd.mjs` encoder. No fetched binary, compiler installation, worker,
shared memory, threads, COOP or COEP is required. Rebuild with:

```
node src/app/madfun/beerio-2/build-road-simd.mjs
```

Compilation is lazy and cached. Validation checks actual SIMD instructions;
unsupported WASM/SIMD, CSP failures, invalid geometry and allocation failures
return `null`, allowing callers to retain `indexRoad`. Every query uses static
prepacked segment data with one WASM call for an on-road lookup. Off-road recovery
may call the full-track kernel as well.

## Evidence, not a frame-rate claim

Run the repeatable numerical tests and diagnostic benchmark:

```
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --test src/app/madfun/beerio-2/road-simd.test.mjs
```

Node 24.22.1, Linux execution environment, 131,072 on-road queries, warmed,
median of seven runs (2026-11-15):

| Course | Indexed JS | Indexed SIMD128 | Relative query speed |
| --- | ---: | ---: | ---: |
| Seattle | 38.76 ms | 26.21 ms | 1.48x |
| Orbit | 36.62 ms | 25.49 ms | 1.44x |

This measures the full query wrapper, including lookup, boundary crossing and
result allocation, not just arithmetic. It excludes initialization. It does not
measure browser frame rate or promise identical speedups on other hardware.
Road queries are a small part of the complete rendering/physics frame, so the
absolute frame-time saving is small with only four drivers.

The tests compare 20,396 point/seam/random off-road queries across both courses
against the indexed scalar implementation: identical segment IDs and every
numeric field within 1e-10. Tests also cover empty/degenerate geometry, missing
WebAssembly and a simulated compile rejection. Timing is reported rather than
used as a flaky pass/fail threshold.
